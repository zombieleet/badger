# badger

A conference-badge firmware for the [Pimoroni Badger 2040 W](https://shop.pimoroni.com/products/badger-2040-w), written in Go and built with [TinyGo](https://tinygo.org).

On boot it shows a pixel-art "WELCOME" banner on the 296×128 e-ink display. From there, a small button-driven menu lets you pick a screen. The **Badge** screen shows a name, LinkedIn and GitHub handles, and a Go gopher.

## Hardware

- Pimoroni Badger 2040 W (RP2040, UC8151 e-ink panel)
- USB cable for flashing

## Requirements

- Go 1.26+
- TinyGo 0.43+ (the build target is `badger2040-w`, also recorded in `.tinygo-target`)

## Build and flash

Connect the badge over USB, then run:

```sh
tinygo flash -target=badger2040-w ./cmd/badger
```

If the board isn't detected, hold **BOOT/USR** while pressing **RST** to put it in bootloader mode, then run the command again.

To build without flashing:

```sh
tinygo build -target=badger2040-w -o badger.uf2 ./cmd/badger
```

Copy `badger.uf2` onto the `RPI-RP2` drive that appears in bootloader mode.

## Controls

| Button | Action |
|--------|--------|
| **A**  | Open the menu; press again to move to the next item |
| **B**  | Open the highlighted item |
| **UP** | Toggle display power |

The onboard LED blinks three times when the firmware is ready.

## Make it your own

Your badge details are constants at the top of `internal/screen/badge.go`:

```go
const (
	badgeFirstName = "Victory"
	badgeLastName  = "Osikwemhe"
	badgeLinkedIn  = "victoryosikwemhe"
	badgeGithub    = "zombieleet"
)
```

### Changing the images

The gopher and contact icons are 1-bit bitmaps compiled into the firmware. The source PNGs are in `internal/screen/assets/`. The bitmaps are generated by `tools/img2bmp`, a regular Go program that runs on your computer, not on the badge.

After replacing an image, regenerate the bitmaps:

```sh
go generate ./internal/screen
```

Sizes and names for each bitmap are set in `internal/screen/gen.go`. To convert a single image by hand:

```sh
go run ./tools/img2bmp -in path/to/image.png -name logo -w 64 -h 64 -o internal/screen/logo_bmp.go
```

| Flag    | Default  | Description |
|---------|----------|-------------|
| `-in`   |          | Input PNG or JPEG |
| `-name` | `img`    | Prefix for the generated `<name>W`, `<name>H` and `<name>Bmp` identifiers |
| `-w`, `-h` | original size | Output size in pixels (nearest-neighbour scaling) |
| `-t`    | `128`    | Brightness threshold (0–255). Pixels darker than this become black |
| `-pkg`  | `screen` | Package name for the generated file |
| `-o`    | stdout   | Output file |

Transparent pixels are left white.

## Project layout

```
cmd/badger/          entry point: sets up the display, buttons and LED
internal/screen/     drawing: welcome banner, menu, badge, bitmaps
internal/button/     button interrupts and menu navigation
internal/blinky/     LED blink helper
tools/img2bmp/       PNG/JPEG → Go byte slice converter
```
